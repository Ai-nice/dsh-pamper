关于此预览页

静态页 · 无需构建 · 不加载第三方 JS

如何打开

页面通过 HTTP 加载 manifest.json 并直连 jsDelivr CDN，请用静态服务器打开：

cd "pamper"
node scripts/serve.mjs
# 浏览器打开 http://127.0.0.1:8899/preview/

# 在 preview/ 目录下时等价于：
# node ../scripts/serve.mjs

也可用任意静态服务器（如 npx serve .、python -m http.server）。直接双击页面以 file:// 打开时，浏览器会拦截本地 JSON 请求，页面会显示失败原因。

数据来源

形象与动作来自 aboutme-pets 素材商店，精灵图由 jsDelivr 远程加载；preview/manifest.json 由项目脚本生成，页头会显示加载状态与动作数量。

素材许可

aboutme-pets 素材禁止商用；蓝毛小女仆素材来自 dsh-pet（CC BY-NC-SA 4.0，此处仅作预览演示）；本页代码 MIT。

预览页只读取公开 CDN，不会写入或修改任何素材。

已知限制

精灵图为超大拼图（单张约 42MP、1–2.5MB），首次播放某动作需从 CDN 下载并解码；为控制内存，页面按约 0.65 倍解码，极大倍率放大时会略软。需要支持 WebP 的现代浏览器；CDN 较慢时点击动作会有加载延迟。
