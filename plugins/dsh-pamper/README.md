# 宠爱 / Pamper

完全独立的 DSH 桌宠插件：自带宠爱页面、数据目录、宠物渲染层和动作库，**不依赖 dsh-pet**。

## 功能

- **宠爱页面**：角色 / 桌宠配置 / 发现 三个 tab；
- **多形象同屏**：角色卡片开关、全部显示/隐藏、详情、改名、尺寸、角落位置；
- **页面内浮层**：在 DSH 页面右下角显示当前陪伴的角色；
- **Windows 桌面透明窗**：WPF 无边框透明窗口，逐帧播放宠物动画；
- **动作按需下载**：发现页加载透明 WebM 动作，可随时卸载；
- **基础形象包自动安装**：首次使用自动下载 9 个角色（大肥鱼 + 8 个扩展角色）；
- **自有数据目录**：`%DSH_HOME%/pamper`，不读取/修改 dsh-pet 的运行文件。

## 安装

```text
dsh-pamper
```

在 DSH「添加插件」中填包名即可；首次打开宠爱页面时如无角色，点「安装基础形象包」。

## 桌面模式

- 仅 Windows；
- 首次使用会把当前待机 WebM 转成 PNG 帧（内置 `@ffmpeg-installer/ffmpeg`，无需手动安装）；
- 角色/配置变化会自动刷新桌面窗口；
- 停止插件或关闭 DSH 时自动关闭桌面 helper。

## 数据位置

```text
%DSH_HOME%/pamper/pets                 角色配置、头像、动画
%DSH_HOME%/pamper/desktop-frames       桌面模式 PNG 帧缓存
%DSH_HOME%/pamper/state.json           页面状态
```

## 说明

- 本插件不依赖 dsh-pet；如果本机已有 dsh-pet，首次启动只做一次只读配置迁移，之后不再读写它。
- 桌面模式需要 Windows；页面内浮层全平台可用。
- 更新：用 npm 包名安装后，DSH 会检测新版本并提示更新，无需卸载。
